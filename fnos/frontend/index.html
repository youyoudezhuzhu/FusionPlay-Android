          音频校准

          0 dB

          0 dB 为原始电平，仅支持衰减以避免削波；用于平衡不同音箱的响度。

          0 ms

          用于多音箱播放对齐：数值越大，该音箱输出越晚（0–2000 ms）。

          独立音量曲线 当前音箱

          曲线为理论映射，不是声压测量。横轴为发送端音量（0–100%），纵轴为当前音箱输出幅度（0–100%）。

          首尾固定为 0% / 0% 与 100% / 100%；控制点须单调不减。可拖动、用方向键微调或直接输入数值。

          输出设备测试

          播放约 1 秒的真实测试音，用于确认该音箱已经接通。
          高级音频参数

          0 = 跟随设备默认采样率。
