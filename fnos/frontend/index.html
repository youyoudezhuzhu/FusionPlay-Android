接收协议

开启 / 关闭协议、广播名称、网络接口与发现状态。保存后写入后端 config.json，并由后端重启协议宿主生效。

保存协议设置

有未保存修改

广播名称写入 config.receiver.name，网络接口写入 config.receiver.interface（留空 = 自动选择）。三个协议共用这两项。保存时后端会按新配置重启协议宿主（无需手动重启）；若重启失败，配置可能已写入，本页会明确提示，并可在「设置 / 诊断」查看日志。

音频输出

多设备播放同一音源；每设备独立缓冲、重采样、漂移与延迟补偿。

响度范围 −30–0 dB（0 = 原始电平，后端不提供正增益以避免削波）；延迟补偿 0–2000 ms；默认格式 = 每设备首选采样率（0 表示跟随设备）。保存时先 PUT /api/config，再 POST /api/devices/refresh。设备消失时保留配置并给出提示，可在此移除。

音频校准

这些参数不是发送端主音量：只影响 NAS 侧输出增益，不会改写手机 / 电脑上显示的音量。

全局输出

有未保存修改 —

曲线把发送端逻辑音量（0–100%）映射为输出幅度；总增益 = 曲线 × 全局衰减 × 每设备 dB。后端不支持每设备独立曲线覆盖，仅支持全局曲线 + 每设备 dB / 延迟。
